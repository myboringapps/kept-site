# kept-site

Public pages for the Kept iOS app, served by GitHub Pages at https://myboringapps.github.io/kept-site/

- `privacy.html`: Privacy Policy (App Store "Privacy Policy URL")
- `support.html`: Support (App Store "Support URL")
- `terms.html`: Terms of Use
- `faq.html`: Frequently asked questions (expandable `<details>`; keep answers in sync with the app)

Plain HTML and CSS, no build step. Edit a page, commit, push; GitHub Pages updates within a minute.
Source drafts live in the app repository under `docs/`.
